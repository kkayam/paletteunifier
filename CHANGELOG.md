# Changelog

## 0.3.0
- Moss, nails, iron bands, gold and other non-wood details are now left untouched: the conditional
  mode checks hue and colourfulness as well as colour distance.
- Chipped now uses the conditional mode by default (existing configs are migrated).
- New settings: `hueTolerance`, `chromaGuard`.

## 0.2.0
- In-game settings screen through Mod Menu + Cloth Config.
- `/paletteunifier on` and `/paletteunifier off`.

## 0.1.0
- First version: recolors mod wood textures to match the active resource pack.
